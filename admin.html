Store admin

Manage products, prices, discounts, photos and website settings.

How to get your access key (one time)
  1. Sign in to GitHub as rangesaleha and open github.com/settings/personal-access-tokens/new.
  2. Token name: Store admin. Expiration: 366 days.
  3. Repository access: Only select repositories → rangesaleha.github.io.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it and paste it above. Keep it private — anyone with it can edit the website.
